# Snake Eyes

A dice game, built up in steps. Each folder is a complete working version, and each one builds on the one before.

1. [01_basic](01_basic/) – the simple game, with no functions or tests
2. [02_functions](02_functions/) – split the code into functions
3. [03_tests](03_tests/) – add tests with pytest
4. [04_auto_roll](04_auto_roll/) – add an auto-roll function
5. [05_file_import](05_file_import/) – split the code across files and import it
