# Turtle

Drawing with Python's built-in `turtle` module.

- [basics](basics/) – your first turtle drawings. Run any file with `python3 <file>.py`.
  - `square.py` – draw a square
  - `square_loop.py` – draw a square using a loop
  - `circle.py` – an animated circle
  - `spiral.py` – a spiral that grows outwards
- [turtle_race](turtle_race/) – bet on a turtle and watch them race, with power-ups along the way
- [space_rescue](space_rescue/) – fly a starship to rescue floating astronauts and dodge the asteroids, built up step by step
