# Turtle

Drawing with Python's built-in `turtle` module. Run any file with `python3 <file>.py`.

- `square.py` – draw a square
- `square_loop.py` – draw a square using a loop
- `circle.py` – an animated circle
- `spiral.py` – a spiral that grows outwards
- `turtle_race.py` – turtles racing across the screen
